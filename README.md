# Корея 2026

Статичная страница-лендинг с маршрутом поездки (Сеул → Кёнджу → Ульсан → Пусан → Сеул), 28 октября — 12 ноября 2026: перелёты, отели на каждую ночь, план по дням (транспорт, время поездов) и места с фото.

Зависимостей нет, сборки нет: обычный HTML, CSS и немного JS.

## Запуск

Самый простой способ: открыть файл `index.html` двойным щелчком.

Через локальный сервер (любой вариант):

```
npm start              # http://localhost:5173, нужен Node.js
python -m http.server 5173
```

## Структура

- `index.html` — вся страница (разметка, стили, скрипт обратного отсчёта)
- `assets/city-1..4.jpg` — фото городов: Сеул, Кёнджу, Ульсан, Пусан
- `assets/place-01..38.jpg` — фото мест в порядке появления на странице (по дням)

## Заметки

- Шрифты (Unbounded, Golos Text, Noto Serif KR) подгружаются с Google Fonts. Без интернета страница откроется с системными шрифтами.
- Ссылки «Фото ↗» ведут на поиск картинок Google и требуют интернета.
- Фото взяты с Wikimedia Commons по свободным лицензиям (CC0, CC BY, CC BY-SA). Автор и лицензия каждого снимка указаны в блоке «Авторы фотографий» внизу страницы. При публикации страницы публично этот блок нужно сохранить.
- Обратный отсчёт считается от вылета 27.10.2026 22:30 по времени Ташкента (`index.html`, блок `<script>` в конце).
