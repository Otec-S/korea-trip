# Корея 2026

Отчёт о поездке Сергея и Ирины по Южной Корее, 28 октября — 12 ноября 2026: Сеул → Кёнджу → Ульсан → Пусан → Сеул.

- Наверху — обложка из четырёх городов, поездка в цифрах, схема маршрута и «Корея в пяти фразах». Меню разделов прилипает к верху экрана.
- Для каждого дня — короткий рассказ, наши фото и свёрнутый план «как планировали»; дни, где план поменялся, отмечены. Кнопка «ещё N фото этого дня» открывает просмотр по фото этого дня.
- Для каждого города — галерея «Все фото» со всеми снимками из папки города, свёрнутая по умолчанию.
- В конце — «Впечатления».

Сборки нет: обычный HTML, CSS и немного JS. Публикуется через GitHub Pages.

## Запуск

Открыть `index.html` двойным щелчком или запустить локальный сервер:

```
npm start              # http://localhost:5173
python -m http.server 5173
```

## Фото

Оригиналы в репозиторий не попадают: они лежат в папках по городам (`Сеул`, `Кёнджу`, `Ульсан`, `Пусан`). Сайт использует сжатые копии из `assets/photos/<город>/`:

- `<имя>.webp` — до 1600 px по длинной стороне;
- `<имя>-m.webp` — до 960 px для телефонов: в полноэкранном просмотре на узком экране грузится она, на широком — полная;
- `<имя>-t.webp` — превью до 480 px;
- `photos.json` — отобранные фото с подписями и датами (дни, обложки, счётчики);
- `photos.js` — то же как `window.TRIP_PHOTOS` плюс `window.TRIP_ALL_PHOTOS` со всеми фото из папок городов (для галерей «Все фото»). Страница читает `photos.js`, чтобы работать и без сервера.

Все метаданные (EXIF, геометки) при сжатии удаляются.

`assets/og-cover.jpg` — превью для мессенджеров (1200×630) из обложек городов. Адрес в `og:image` и `og:url` в `index.html` должен совпадать с адресом сайта на GitHub Pages.

Пересобрать фото (нужны Python, Pillow и `pillow-heif`):

```
python3 tools/build_photos.py index  --src-root <папка с папками городов>   # опись и контактные листы в .work/
python3 tools/build_photos.py sheets
python3 tools/build_photos.py build  --src-root <папка с папками городов>   # все фото из папок; подписи из tools/selection.json
python3 tools/build_photos.py check                                       # падает, если в фото остались метаданные
```

В галереи «Все фото» попадают все фото из папок городов (видео пропускаются). Подписи неотобранных фото лежат в `tools/captions.json` (имя файла → подпись). Фото, снятые после 10 ноября 14:00, но лежащие в папке «Пусан», сборка относит к Сеулу (`MISFILED` в `tools/build_photos.py`). В `tools/selection.json` задаются отобранные фото с подписями: они идут в полоски по дням и на обложки. Поле `from` нужно, если снимок лежит в папке другого города.

## Тесты

```
npm i
npx playwright install chromium
npx playwright test
```

Проверяют галереи городов со всеми фото, фото по дням, раздел «Впечатления», загрузку всех картинок, просмотр фото на весь экран, отсутствие ошибок в консоли и горизонтальной прокрутки на телефоне.

Отдельный блок `mobile viewer` эмулирует телефон с сенсорным экраном: свайпы в просмотре фото, кнопку «Назад», открытие нужного фото после листания и на медленном интернете. Если Chromium не скачан, можно указать установленный Chrome: `PW_CHROME=/usr/bin/google-chrome npx playwright test`.

Фото для полосок по дням задаются в `index.html` атрибутом `data-pick="город:имя_файла,..."` (имя без `.webp`), поэтому пересборка фото не сдвигает подборки.
