# Корея 2026

Отчёт о поездке Сергея и Ирины по Южной Корее, 28 октября — 12 ноября 2026: Сеул → Кёнджу → Ульсан → Пусан → Сеул.

- Наверху — обложка из четырёх городов, поездка в цифрах, схема маршрута и «Корея в пяти фразах». Меню разделов прилипает к верху экрана.
- Для каждого дня — короткий рассказ, наши фото и свёрнутый план «как планировали»; дни, где план поменялся, отмечены. Кнопка «ещё N фото этого дня» открывает просмотр по фото этого дня.
- Для каждого города — полная галерея, свёрнутая по умолчанию.
- В конце — «Впечатления» и свёрнутый блок «Для тех, кто поедет по нашему маршруту»: рейсы, жильё, переезды.

Сборки нет: обычный HTML, CSS и немного JS. Публикуется через GitHub Pages.

## Запуск

Открыть `index.html` двойным щелчком или запустить локальный сервер:

```
npm start              # http://localhost:5173
python -m http.server 5173
```

## Фото

Оригиналы в репозиторий не попадают: они лежат в папках по городам (`Сеул`, `Кёнджу`, `Ульсан`, `Пусан`). Сайт использует сжатые копии из `assets/photos/<город>/`:

- `<имя>.webp` — до 1600 px по длинной стороне;
- `<имя>-t.webp` — превью до 480 px;
- `photos.json` и `photos.js` — список фото с подписями и датами (страница читает `photos.js`, чтобы работать и без сервера).

Все метаданные (EXIF, геометки) при сжатии удаляются.

`assets/og-cover.jpg` — превью для мессенджеров (1200×630) из обложек городов. Адрес в `og:image` и `og:url` в `index.html` должен совпадать с адресом сайта на GitHub Pages.

Пересобрать фото (нужны Python, Pillow и `pillow-heif`):

```
python3 tools/build_photos.py index  --src-root <папка с папками городов>   # опись и контактные листы в .work/
python3 tools/build_photos.py sheets
python3 tools/build_photos.py build  --src-root <папка с папками городов>   # по tools/selection.json
python3 tools/build_photos.py check                                       # падает, если в фото остались метаданные
```

Какие фото попадают на сайт и с какими подписями, задаётся в `tools/selection.json`. Поле `from` нужно, если снимок лежит в папке другого города.

## Тесты

```
npm i
npx playwright install chromium
npx playwright test
```

Проверяют галереи городов, фото по дням, раздел «Впечатления», загрузку всех картинок, просмотр фото на весь экран, отсутствие ошибок в консоли и горизонтальной прокрутки на телефоне.
